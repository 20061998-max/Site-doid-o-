## 🚀 Como lançar pelo GitHub

### Opção 1: Lançamento Automático pelo GitHub Pages (100% Gratuito)

1. Crie um novo repositório no seu [GitHub](https://github.com/new) com o nome: `doidao-downloads`.
2. No seu computador, abra a pasta do projeto no terminal e execute:
   ```bash
   git init
   git add .
   git commit -m "Lançamento oficial Doidão Downloads"
   git branch -M main
   git remote add origin https://github.com/SEU_USUARIO/doidao-downloads.git
   git push -u origin main
   ```
3. No GitHub, vá na aba **Settings** > **Pages**:
   * Em **Source**, selecione **GitHub Actions**.
   * O fluxo `.github/workflows/deploy.yml` que já deixamos configurado fará o build e publicará seu site em segundos!
   * O seu link será: `https://SEU_USUARIO.github.io/doidao-downloads/`

---

### Opção 2: Lançamento pelo Render.com (Igual ao site da foto: `devstorepro.onrender.com`)

1. Crie uma conta gratuita no [Render.com](https://render.com/).
2. Clique em **New +** > **Static Site**.
3. Conecte sua conta do GitHub e selecione o repositório `doidao-downloads`.
4. Preencha as opções:
   * **Build Command**: `npm install && npm run build`
   * **Publish Directory**: `dist`
5. Clique em **Create Static Site**.
6. Pronto! O Render gerará seu link instantâneo (ex: `doidaodownloads.onrender.com`).

---

### Opção 3: Lançamento pelo Vercel (Recomendado pela velocidade)

1. Acesse [vercel.com](https://vercel.com/) e entre com o GitHub.
2. Clique em **Add New...** > **Project**.
3. Importe o repositório `doidao-downloads`.
4. O Vercel detectará o Vite automaticamente. Clique em **Deploy**.
5. Seu link ficará no ar em 30 segundos (ex: `doidao-downloads.vercel.app`).
